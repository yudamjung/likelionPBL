# Frontend PBL

멋쟁이사자처럼 프론트엔드(React) 트랙의 PBL 과제를 제출하기 위한 레포지토리입니다.

HTML/CSS 기초부터 JavaScript, React, TypeScript, Supabase 연동, 최종 서비스 구현까지  
주차별 미션을 진행하며 학습한 내용을 기록합니다.

---

## Curriculum

| 주차 | 미션 | 핵심 키워드 |
| --- | --- | --- |
| 1주차 | HTML/CSS 기초 | Tag, Semantic, Box Model |
| 2주차 | CSS 레이아웃 & 반응형 | Grid, Position, Media Query |
| 3주차 | JavaScript 기초 | DOM, Event, Variable |
| 4주차 | JS 비동기와 데이터 | Fetch, Promise, Async/Await |
| 5주차 | React 시작하기 | Component, JSX, Props |
| 6주차 | 상태와 Effect | useState, useEffect |
| 7주차 | React Router | Link, useParams, Route |
| 8주차 | TypeScript 기초 | Type, Interface, Props Type |
| 9주차 | Supabase 연동 | Supabase Client, CRUD |
| 10주차 | 최종 서비스 완성 | Vercel/Netlify, Refactoring |

## Goal
주차별 PBL 미션을 수행하며 단순히 문법을 익히는 것에 그치지 않고,
- 웹의 기본 구조 이해
- 반응형 UI 구현
- JavaScript를 활용한 동적 기능 구현
- API 및 비동기 데이터 처리
- React 컴포넌트 설계
- 상태 관리와 Side Effect 이해
- 페이지 라우팅 구현
- TypeScript를 활용한 타입 안정성 확보
- Supabase를 활용한 CRUD 구현
- 실제 웹 서비스 배포 및 리팩토링
까지 단계적으로 익히는 것을 목표로 합니다.
