## Troubleshooting — 이미지 비율이 1:1로 맞지 않는 문제

### 문제 상황

프로필 카드 내부에 이미지를 넣는 과정에서 원본 이미지의 비율이 1:1이 아니어서, 이미지가 카드 디자인에 맞지 않게 표시되는 문제가 발생했다.

처음에는 이미지 자체에 `width`, `height`, `object-fit: cover`를 적용하거나 `aspect-ratio: 1 / 1`을 사용하는 방식으로 해결하려고 했다.

```css
.profile-summary-card img {
  width: 200px;
  aspect-ratio: 1 / 1;
  object-fit: cover;
}
```

하지만 이미지가 원하는 1:1 영역에 맞춰지지 않았다.

---

### 원인

`object-fit: cover`는 이미지 자체를 강제로 정사각형으로 만드는 속성이 아니라, **이미지가 들어갈 영역을 기준으로 비율을 유지하면서 채우는 속성**이다.

따라서 이미지가 들어갈 영역의 크기가 명확하게 정해져 있지 않으면 기대한 형태로 잘리지 않을 수 있다.

즉, 이미지 자체의 스타일뿐만 아니라 **이미지가 들어갈 컨테이너의 크기를 먼저 고정할 필요가 있었다.**

---

### 해결 방법

이미지를 감싸는 `.profile-image` 요소에 `width`와 `height`를 동일하게 지정하여 200px × 200px의 정사각형 영역을 만들었다.

또한 `overflow: hidden`을 적용해 해당 영역을 벗어나는 이미지 부분이 보이지 않도록 처리했다.

```css
.profile-image {
  width: 200px;
  height: 200px;
  overflow: hidden;
}

.profile-summary-card img {
  width: 200px;
  aspect-ratio: 1 / 1;
  object-fit: cover;
}
```

이를 통해 `.profile-image`가 이미지의 표시 영역을 1:1 비율로 제한하고, `object-fit: cover`가 원본 이미지의 비율을 유지하면서 해당 영역을 채우도록 만들었다.

영역을 벗어나는 부분은 `overflow: hidden`에 의해 잘려서 보이지 않게 된다.

---

### 결과

원본 이미지의 비율이 1:1이 아니더라도 프로필 카드에서는 항상 200px × 200px 크기의 정사각형 이미지로 표시되도록 수정할 수 있었다.

이미지를 억지로 늘리거나 줄이지 않고 원본 비율을 유지하면서 필요한 부분만 잘라낼 수 있었다.

---

### 배운 점

- `object-fit: cover`는 이미지의 비율 자체를 변경하는 속성이 아니라, 지정된 영역을 이미지가 채우도록 하는 속성이다.
- 이미지 크롭이 필요한 경우 이미지 요소만 조절하는 것보다, 이미지가 들어갈 컨테이너의 크기를 먼저 지정하는 방식이 효과적이다.
- `overflow: hidden`을 사용하면 컨테이너 영역을 넘어가는 이미지 부분을 자연스럽게 숨길 수 있다.
- CSS 문제를 해결할 때는 이미지 자체의 스타일뿐만 아니라 부모 요소의 크기와 레이아웃도 함께 확인해야 한다.
