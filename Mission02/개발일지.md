# Mission 02 개발일지

## 반응형 카드 레이아웃 트러블슈팅

### 문제 상황

아기사자 프로필 카드를 반응형 그리드로 배치하던 중 두 가지 문제가 발생했다.

1. 데스크톱에서 한 줄에 카드 3개를 배치했지만 브라우저 너비를 늘리면 카드의 크기가 일정하게 유지되지 않았다.
2. 프로필 이미지 위에 표시해야 하는 배지가 각 이미지가 아니라 브라우저 화면을 기준으로 움직였다.

### 문제 1. 카드 너비가 달라지는 현상

처음에는 데스크톱 그리드를 다음과 같이 구성했다.

```css
grid-template-columns: 320px 1fr 1fr;
```

이 설정에서는 첫 번째 열만 `320px`로 고정되고, 두 번째와 세 번째 열은 `1fr`로 남은 공간을 나눠 가진다. 따라서 브라우저 너비가 커지면 `1fr` 열의 카드도 함께 늘어나는 것이 정상적인 동작이었다.

또 다른 원인은 미디어 쿼리의 조건이었다. 데스크톱 규칙과 태블릿 규칙을 모두 `min-width`로 작성했기 때문에 화면 너비가 1024px 이상이면 두 규칙이 모두 적용되었다. CSS에서는 같은 우선순위의 규칙이 겹칠 때 뒤에 작성된 규칙이 앞의 규칙을 덮어쓴다. 그 결과 데스크톱에서도 태블릿의 2열 설정이 적용될 수 있었다.

### 해결 방법

- 태블릿 미디어 쿼리에 `max-width: 1023px`를 추가해 태블릿과 데스크톱 조건이 겹치지 않게 했다.
- 각 열의 크기를 동일하게 유지하기 위해 `repeat()`과 고정된 열 너비를 사용했다.
- 카드 묶음이 화면 가운데에 오도록 `justify-content: center`를 적용했다.

```css
/* 태블릿 */
grid-template-columns: repeat(2, 340px);

/* 데스크톱 */
grid-template-columns: repeat(3, 350px);
```

이제 각 열이 같은 크기를 사용하므로 브라우저 너비가 커져도 카드 자체가 임의로 늘어나지 않는다.


## 문제 2. 배지가 이미지 기준으로 고정되지 않는 현상

배지에는 `position: absolute`를 사용했지만 배지의 부모 요소인 `.profile-img`에는 위치 기준을 지정하지 않았다.

`position: absolute`인 요소는 가장 가까운 `position`이 설정된 조상 요소를 기준으로 배치된다. 기준이 되는 조상 요소가 없으면 브라우저의 초기 containing block을 기준으로 계산된다. 그래서 배지가 각 프로필 이미지가 아니라 페이지 전체를 기준으로 움직이는 것처럼 보였다.

### 해결 방법

프로필 이미지 영역을 배지의 기준으로 지정했다.

```css
.profile-img {
    position: relative;
}
```

이후 배지의 `top`과 `right` 값은 각 `.profile-img` 영역의 우측 상단을 기준으로 계산된다. 따라서 브라우저 크기를 변경해도 배지가 해당 프로필 이미지 위에 붙어 있는 위치를 유지한다.

## 배운 점

### 1. `1fr`는 고정 크기가 아니다

`1fr`은 남은 공간을 나누는 단위이므로 화면 크기에 따라 계속 변한다. 카드 크기를 고정하려는 경우에는 고정된 열 너비를 사용해야 하고, 화면 크기에 따라 카드도 유연하게 바꾸려는 경우에는 `1fr`을 사용하는 것이 적절하다.

### 2. 미디어 쿼리는 조건이 겹치는지 확인해야 한다

`min-width`만 여러 개 작성하면 큰 화면에서 작은 화면용 규칙까지 동시에 적용될 수 있다. 모바일을 기본 스타일로 두고 태블릿, 데스크톱 순서로 규칙을 추가하거나, 각 구간에 `max-width`를 함께 지정해 조건이 겹치지 않도록 해야 한다.

### 3. `position: absolute`에는 기준점이 필요하다 ⭐️

오버레이 요소를 특정 컴포넌트 안에 고정하려면 부모 요소에 `position: relative`를 지정해야 한다. 화면 전체를 기준으로 배치하는 것이 아니라, 원하는 컴포넌트를 기준으로 좌표를 계산하도록 만드는 것이 핵심이다.

## 회고

처음에는 화면을 넓힐 때 특정 카드만 커지는 현상을 카드 자체의 문제라고 생각했다. 그러나 실제로는 그리드 열 정의와 미디어 쿼리 적용 범위를 먼저 확인해야 했다. CSS 레이아웃 문제는 보이는 요소 하나만 수정하기보다, 부모의 레이아웃 규칙과 자식의 위치 기준을 함께 추적해야 원인을 정확히 찾을 수 있다는 점을 배웠다.

## 문제 3. 모바일 프로필 이미지가 가운데로 보이지 않는 현상

### 문제 상황

모바일 화면에서 카드의 프로필 이미지가 왼쪽으로 치우쳐 보이고, 오른쪽 여백이 더 크게 보였다. 태블릿과 데스크톱에서는 같은 현상이 눈에 띄지 않았다.

### 원인

카드는 콘텐츠 너비가 `300px`이고 좌우 패딩이 `20px`이다. 그런데 모바일 기본 스타일의 이미지만 `280px`로 지정되어 있었다.

```css
.baby-lion-card {
    width: 300px;
    padding: 20px;
}

/* 기존 모바일 스타일 */
.baby-lion-card img {
    width: 280px;
}
```

이미지가 카드 콘텐츠보다 `20px` 작기 때문에 기본 정렬 기준인 왼쪽에 붙었고, 오른쪽에 빈 공간이 남았다. 태블릿과 데스크톱에서는 미디어 쿼리에서 이미지도 `300px`로 지정했기 때문에 카드 콘텐츠 너비와 같아 이 문제가 보이지 않았다.

### 수정

이미지 너비를 고정값 대신 부모 콘텐츠 영역에 맞추도록 변경했다.

```css
.baby-lion-card img {
    display: block;
    width: 100%;
    aspect-ratio: 1 / 1;
    object-fit: cover;
}
```

`width: 100%`는 모바일·태블릿·데스크톱에서 현재 카드 콘텐츠 너비를 항상 채우므로 이미지 크기를 미디어 쿼리마다 반복해서 지정할 필요가 없다. `display: block`은 이미지 아래에 생길 수 있는 인라인 요소 특유의 여분 공간도 제거한다.



## 추가로 확인한 개선점

- 이미지 스타일을 미디어 쿼리에서 반복하지 않고 기본 규칙 하나로 통합했다.
- `.profile-img`의 `width: auto`, `height: auto`와 `.detail-card`의 `width: auto`, `height: auto`는 기본값과 같아서 삭제해도 된다.
- `.baby-lion-card img`에 있던 `overflow: hidden`은 이미지보다 부모인 `.profile-img`에서 처리하고 있으므로 불필요하다.
- 상세 카드 HTML에는 반복되는 `</div>`가 많아 일부 카드가 `.detail-profile-card-area` 밖에 놓여 있다. 레이아웃이 이상해질 때는 상세 카드들의 여는 태그와 닫는 태그를 먼저 정리하는 것이 좋다. -- 수정 완료.
